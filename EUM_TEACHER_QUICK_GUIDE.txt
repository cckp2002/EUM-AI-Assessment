이음(E-UM) 평가도구 설계 스튜디오 · F19
접속: https://cckp2002.github.io/EUM-AI-Assessment/

교과 지식을 삶에 연결하는 서·논술형 평가도구를 AI와 함께 설계합니다.
가입·설치 없이 사용합니다. AI 없이 직접 작성·편집할 수도 있습니다.

1. ‘새 평가도구 만들기’를 누르고 교과와 성취기준을 선택합니다.
2. ‘API 키 설정’에서 본인의 OpenAI API 키를 입력합니다.
   AI 사용료는 키 소유자에게 발생합니다. 키는 이 브라우저의 메모리에만 보관합니다.
3. ① 성취기준 선택 → ② 분석 → ③ 평가요소 선택·수정
   → ④ 평가 과제 설계 → ⑤ 비계·핵심 질문 구성으로 진행합니다.
4. ⑥ ‘AI 루브릭 전체 생성’ 후 내용을 읽고 활용할 초안에
   ‘이 루브릭을 평가도구에 사용하기’를 선택한 뒤 ‘생성 결과 사용’을 누릅니다.
   사용 선택은 최종 확정이 아닙니다. 부족한 수준과 판단 경계는 교사가 보완합니다.
5. ⑦ 최종 검토에서 기대수행과 공식 근거를 확인·수정합니다.
   학생용·교사용 미리보기에서 ‘인쇄 / PDF 저장’을 이용합니다.
6. 상단 ‘작업 파일 저장’으로 .eum 파일을 자주 내려받으세요.
   나중에 ‘이어서 작업하기’로 파일을 열면 다른 기기에서도 이어 할 수 있습니다.

주의
• 실제 학생 이름·학번·개인정보는 입력하지 마세요.
• 브라우저 기록은 영구 보관이 아닙니다. 새로고침·종료 전 .eum을 저장하세요.
• 키를 공유하거나 작업 파일에 적지 마세요. 브라우저 확장 프로그램·악성코드는
  입력한 키에 접근할 수 있으므로 신뢰할 수 있는 기기에서 사용하세요.
• 오류·처리 여부 미확인이 나오면 반복 생성하지 말고 현재 작업 파일부터 보관하세요.
• 공용 PC에서는 파일을 안전하게 옮긴 후 키를 제거하고 ‘작업 종료’를 하세요.
  이전 작업 목록에서 본인의 임시 작업만 확인하여 정리하세요.

행사 준비: 행사 전용 키, 예산 상한, 브라우저·인터넷·PDF 출력·작업 파일 저장을
운영자가 사전 확인합니다. 별도의 행사 모드나 공용 키 배포 기능은 없습니다.
